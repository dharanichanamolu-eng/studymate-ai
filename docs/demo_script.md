# Demo script (60–90 seconds)

**Before recording:** FalkorDB running, `streamlit run app.py` open, sidebar in **My study memory** mode with a fresh Student ID (e.g. `demo-1`) so the graph is empty. Browser zoom ~110%. Screen recorder on.

| Time | Do | Say (suggested) | Expected on screen |
|---|---|---|---|
| 0:00–0:10 | Show the home page | "StudyMate AI is a study assistant that remembers what you learn, using a FalkorDB knowledge graph." | Banner, **FalkorDB: connected**, LLM status (fallback or configured), empty weak areas |
| 0:10–0:30 | Type exactly: `I studied Python loops today. I understand for loops, but nested loops are difficult for me.` | "I tell it what I studied and what was hard." | "✅ Saved to FalkorDB" with Subject Python, Understood: for loops, Difficult: nested loops |
| 0:30–0:40 | Point to sidebar + graph panel | "That is now stored in FalkorDB: a Student, the Python subject, topics, and a study session." | Sidebar: red pill "nested loops · Python · 4/5", green pill "for loops". Graph panel shows edges |
| 0:40–0:55 | (Optional) reload the browser tab, then type `What should I study next?` | "Even after a reload, the memory is still there because it lives in the database, not the browser." | Recommendation for **Nested Loops** |
| 0:55–1:15 | Scroll the recommendation and open "Recent sessions" | "The reason comes from the retrieved graph memory: I reported difficulty with nested loops and already understand for loops. It gives a plan and practice questions." | "Why (from your graph memory)…", 4-step plan, 5 questions, caption "Generated by: …" (say honestly whether fallback or LLM) |
| 1:15–1:30 | Point at graph panel / show `assets/graph_model.md` | "Relationships: Student STUDIES Subject, Subject CONTAINS Topic, Student COMPLETED a StudySession that COVERS topics, and Student STRUGGLES_WITH a Topic. Recommendations query those edges." | Graph panel / schema |

**Tips:** Do not claim an LLM was used if the caption says "Rule-based fallback". Do not mention multi-agent coordination. Keep under 90 seconds; re-record rather than edit heavily.

## Record and upload
1. Record with OBS, Loom, or the built-in screen recorder (Windows: Win+G; macOS: Shift+Cmd+5).
2. Upload to YouTube as *Unlisted* (or Public), title "StudyMate AI – FalkorDB Hackathon Demo".
3. Paste the real URL into `README.md` and the submission form. Test the link while logged out.
